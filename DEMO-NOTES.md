# Palma Sola design samples

Open index.html to compare five modest community-park designs. Each has Home and Contact/About pages; other navigation is intentionally inactive.

No forms, live data, analytics, scripts or external font downloads. Three small existing site assets are shared by all alternatives. System fonts vary slightly by device. The garden photograph retains its registry credit and licence. Content is a visual sample drawn from explore, not a live visitor-information feed.

Nothing in explore was changed. Files remain uncommitted for Randy. After committing and pushing, GitHub Pages can serve the repository root. Pages include noindex,nofollow; this does not make the demo private.
